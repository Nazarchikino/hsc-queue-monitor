# 🚗 HSC E-Queue Autonomous Monitor Bot

Асинхронний Telegram-бот на базі `aiogram 3` та `Playwright` для цілодобового автономного моніторингу вільних талонів у системі електронної черги Головного сервісного центру МВС України (`eqn.hsc.gov.ua`).

Бот самостійно проходить повний цикл авторизації через **ID.GOV.UA** за допомогою файлового цифрового підпису (КЕП), автоматично оновлює короткоживучі сесії кожні 13 хвилин та дозволяє керувати послугами й сервісними центрами через інтерактивні кнопки в Telegram.

---

## 🌟 Основні можливості

- 🔄 **Автономна фонова авторизація:** вхід через Playwright Firefox з автоматичною обробкою дисклеймерів, чекбоксів та підтвердження передачі даних на ID.GOV.UA.
- ⏱️ **Розумне оновлення сесії:** автоматичний перелогін кожні 13 хвилин (до закінчення 15-хвилинного TTL сесії) без зависання запитів.
- 🎯 **Двокроковий вибір ТСЦ:** фільтрація та вибір сервісних центрів спочатку за областю, а потім за конкретним відділенням.
- 🚗 **Динамічна зміна послуг:** швидке перемикання між категоріями (A, B, C, D, теорія, механіка/автомат) прямо через кнопки в чаті.
- 🛡️ **Обхід блокувань WAF/Akamai:** оптимізована взаємодія через Firefox без викривальних CDP-прапорців.

## 🔑 Отримання та налаштування КЕП (Вчасно або ПриватБанк)

Для авторизації скрипту потрібен файл електронного підпису у форматі `.dat`, `.pfx`, `.pk8`, `.zs2` або `.jks`:

1. **КЕП від «Вчасно»:**
   - Перейдіть на сервіс [Вчасно.КЕП](https://vchasno.ua/kep).
   - Оформіть або перевипустіть безкоштовний ключ.
   - Оберіть варіант **«Файловий підпис»** та збережіть файл ключа (наприклад, `key.dat`).
2. **КЕП від ПриватБанку:**
   - Перейдіть у веб-версію Приват24 (меню «Бізнес» або «Налаштування» -> «Сертифікати КЕП»).
   - Згенеруйте файловий ключ та збережіть його на комп'ютер.
3. Помістіть завантажений файл ключа у папку з ботом та вкажіть його назву й пароль у файлі `.env`.

## 🛠️ Встановлення та запуск

### 1. Встановлення Python
Переконайтеся, що на системі встановлено **Python 3.10** або новішу версію (під час встановлення на Windows обов'язково поставте позначку **«Add Python to PATH»**).

### 2. Клонування репозиторію
```bash
git clone https://github.com/Nazarchikino/hsc-queue-monitor
cd hsc-queue-bot
```

### 3. Створення та активація віртуального середовища
- **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
- **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 4. Встановлення залежностей та рушія браузера
```bash
pip install -r requirements.txt
playwright install firefox
```

### 5. Конфігурація змінних середовища
Створіть файл `.env` поруч із `bot.py` за зразком `.env.example`:
```env
BOT_TOKEN=8754596675:AAH-wyJ...
CHAT_ID=868522557
KEY_FILE_PATH=key.dat
KEY_PASSWORD=ваш_пароль_до_кеп
CA_NAME_EXACT=КНЕДП АЦСК АТ КБ "ПриватБанк"
DEFAULT_DEPT_ID=18
DEFAULT_SERVICE_ID=52
```

> **Важливо:** Якщо ви використовуєте КЕП від Вчасно, вкажіть `CA_NAME_EXACT='КНЕДП ТОВ "Вчасно Сервіс"'`.

### 6. Запуск бота
```bash
python bot.py
```

## 📱 Керування через Telegram

- `/start` або `/menu` — викликає головне меню навігації.
- **«🎯 Обрати ТСЦ (за областями)»** — відкриває список усіх областей України, після натискання на область показує всі діючі сервісні центри цього регіону.
- **«🚗 Змінити вид послуги»** — дозволяє обрати потрібну категорію керування (механіка/автомат, вантажні, легкові, мото тощо).
- **«📊 Поточний статус»** — показує інформацію про поточний обраний центр та кількість доступних талонів онлайн.
- **«🔄 Оновити сесію КЕП»** — ініціює миттєвий примусовий перелогін через Playwright із коректним скиданням таймера сесії.
